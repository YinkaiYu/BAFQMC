# 安全报告

请通过
[GitHub 私密漏洞报告](https://github.com/YinkaiYu/BAFQMC/security/advisories/new)
提交疑似安全漏洞。该方式会将报告发送给仓库维护者，而不会将其公开为 Issue。
请尽可能在报告中注明受影响的提交版本、影响范围以及最小复现步骤；
不要在报告中包含凭据或私密研究数据。

安全修复在当前 `main` 分支上进行。维护者通过私密安全咨询协调调查和披露工作。

若遇到数值计算差异、安装问题或科研方面的疑问，请使用
[公开 Issue 模板](https://github.com/YinkaiYu/BAFQMC/issues/new/choose)，
并附上相关输入、环境信息和处理后的结果。
