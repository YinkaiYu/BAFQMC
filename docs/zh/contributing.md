# 参与贡献

欢迎为 BAFQMC 贡献代码：新的可观测量、算法改进、模型扩展、
计算工作流以及文档完善。所有贡献均遵循仓库的 [MIT 协议](https://github.com/YinkaiYu/BAFQMC/blob/main/LICENSE) 发布。

从 [AGENTS.md](./agents.md) 和[开发指南](./development.md)开始。
对于物理修改，请说明所实现的哈密顿量或估计量，以及它与现有约定的联系。
研究参数使用独立的计算任务，并保持已发布的数据包完整不变。

一个有价值的 Pull Request 应说明问题所在、修改后的行为以及执行的检查。
请包含足够的信息以供他人重复数值检查：
体系尺寸、耦合常数、温度、Trotter 步长、采样量、种子，以及适用时的 ED 截断。
分享小型处理后的结果；将可再生的原始链数据和本地编译输出排除在 Git 之外。

对修改内容运行针对性测试，并执行 `git diff --check`。
对物理估计量的修改应包含小体系对比或恒等式测试。
仅修改文档无需运行完整的生产计算。

Agent 辅助的贡献遵循相同的科学和计算标准。
在提交 Pull Request 之前，请审查生成的代码、数据约定以及报告的测试。
