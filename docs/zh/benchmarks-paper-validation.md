# 数值验证记录

该计算软件包于 2026-09-15 在 Linux/WSL 上完成验证。Fortran 测试使用 Intel `mpiifx` 2025.2.1 和 MKL。Python ED 使用 QuSpin 1.0.1、NumPy 2.4.4、SciPy 1.17.1 和 Numba 0.65.1。图形检查使用 NumPy 2.3.4 和 Matplotlib 3.10.7。

- 全部 Fortran 模型、传播和测量源文件均通过了 `src/common/README.md` 中描述的可移植数值接口编译。
- 矩阵重构、厄米本征系统、求逆和随机序列通过了独立不变量检验。模块化随机递推通过了 150000 次状态转移检查。
- 粒子数守恒实机回归完成了解析自由用例和四个含 100000 个 bin 的相互作用用例。其 Python、参数路由和 ED 内存检查均已通过。
- 配对实机检验覆盖了有限 Delta 和 Delta=0 两种情况。两种独立的小规模 ED 表述在 25 个可观测量和能量导数上吻合。
- 两个求解器均通过了完整的小规模 DQMC → ED → 分析流程测试。生产编排检查涵盖逐用例复制、续算以及从输入重启中断链。
- 一个完整论文规模的配对 ED 计算（Delta=0.2 时 7297 个基矢）在四个参考值上与已跟踪值的绝对偏差在 5.3e-18 以内。
- 全部 22 个用例均从 100000 个样本的测量序列重新进行了分块统计。存储的均值和标准误差与该独立重构结果吻合；紧凑软件包在无原始链的情况下也通过了测试。
- 两份重新生成的图形 PDF 以相同渲染器光栅化至 1800 像素宽后，与论文图形逐像素完全一致。由于元数据可能不同，不要求 PDF 字节完全相同。

上述检验涵盖求解器、参考计算、存储数据和生产编排。完整的 22 点计算是默认复现命令；其时间和内存预算基于 [RESOURCES.md](./benchmarks-paper-resources.md) 中的阶段测量数据。

GNU Fortran/BLAS 编译设置和 GitHub Actions 工作流已提供。该编译器未安装在验证工作站上，因此上述本地运行时结果均指 Intel/MKL 编译版本。CI 在运行时测试 GNU 配置。

## 正文与补充材料映射

复现接口已于 2026-09-15 对照 benchmark 布局进行检验。默认生产计算包含正文中的八点 U1 扫描和七点 Delta 扫描，以及补充材料中的七点 U2 扫描。

- 全部 13 项复现测试通过，包括真实的八 bin BAFQMC/ED 运行、续算和中断链恢复，以及为单个用例选择新的参考计算。恢复计算时会检测所选用例的变化。
- 范围选择保留输入、用例顺序和种子。88 行存储的可观测量保留每个数值；新增列标识当前论文图形和符号。
- 重新生成的 `benchmark_combined.pdf` 和 `benchmark_attractive.pdf` 在光栅化至 1800 像素宽时与当前论文图形逐像素完全一致。正文各行保留 a–d 和 e–h 标签。
- 在 Delta=+0.2 和 -0.2 下进行的 172 态配对 ED 计算得到了相同的密度、物理能量、结构因子、配对能量和自由能。反常 `pair_equal` 振幅符号相反，证实了求解器与论文约定之间所记录的相位转换关系。
