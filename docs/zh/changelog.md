## 0.1.0 — 2026-09-15

BAFQMC 在 MIT 协议下首次公开发布。

- 粒子数守恒和全 Nambu 玻色辅助场蒙特卡洛求解器，
  支持可移植的 MPI Fortran 和 BLAS/LAPACK。
- 精确对角化参考程序以及完整的生产工作流，覆盖主图和补充材料的
  benchmark 图像：共 22 个参数点。
- 原始输入、种子、紧凑型均值和标准误差、分块均值、参考值以及
  可复用的绘图代码。原始测量数据由复现命令生成。
- 自定义计算接口、物理与开发指南、数值测试以及持续集成。
- 独立的有限 Fock ED、解析高斯、固定有相互作用 HS 场
  以及热力学恒等式测试，CI 中含真实 MPI 执行。
- Agent 指令、科研任务技能、环境诊断工具，以及适用于
  GNU Fortran、MPI 和 Python ED 的开发容器。
