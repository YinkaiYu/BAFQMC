# 社区准则

BAFQMC 欢迎来自各种背景和不同经验水平的研究人员和开发者。
请尊重他人，就科学和技术问题就事论事地展开讨论，并对贡献给予恰当的致谢。

骚扰、歧视性言论、人身攻击、威胁以及未经许可披露他人私人信息的行为
均不可接受。上述规范适用于仓库的 Issue、Pull Request 以及其他项目讨论，
包括借助 Agent 工具完成的贡献。

维护者可根据需要编辑或删除不当内容，并限制相关人员的参与资格。
如有行为问题，请通过 [@YinkaiYu](https://github.com/YinkaiYu)
GitHub 个人主页上列出的联系方式私下联系仓库维护者。
请勿在公开 Issue 中包含敏感信息。
